# -Binary-search-code

## Опис
У цьому коді реалізовано бінарний пошук — це спосіб швидко знайти потрібне число в уже відсортованому масиві. Ми не перебираємо всі елементи підряд, а кожного разу ділимо масив навпіл. Функція binarySearch(arr, value) бере масив і значення, яке потрібно знайти. Вона встановлює межі — startIndex і endIndex — і всередині циклу визначає minIndex, тобто середину. Якщо значення в середині збігається з тим, яке шукаємо, — повертаємо позицію. Якщо значення менше, ніж середній елемент, пересуваємо праву межу вліво; якщо більше — пересуваємо ліву межу вправо. Так пошук звужується, поки або знайдемо число, або межі не зійдуться. У кінці код виводить результат — індекс знайденого елемента або -1, якщо його немає.
